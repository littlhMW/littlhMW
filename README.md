## ✦ 关于我

我是一个**美工出身、偶尔写代码的人**。

我会从别人的东西开始，也会自己做东西；看到感兴趣的东西就会折腾一下，然后经常不知不觉地把事情做得比最开始计划的复杂。

我不太在意自己最终会被归类成什么方向。

**Minecraft / D&D / Rain World / UI / 世界观 / 本地化 / 小工具 / 奇怪的实验**

这些东西只要让我觉得「这个可以试试看」，就足够成为一个项目的开始。
